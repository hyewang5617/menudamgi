🍽️ 메뉴담기 사용법

📌 주문하는 방법

1️⃣ 링크 클릭

카톡으로 받은 주문 링크를 클릭하세요

2️⃣ 이름 입력

본인 이름을 입력하고 "메뉴 선택하러 가기" 버튼 클릭

💡 같은 이름으로 다시 들어오면 이전 주문을 수정할 수 있어요!

3️⃣ 메뉴 선택

원하는 메뉴의 + 버튼을 눌러 수량 선택

여러 메뉴 선택 가능

4️⃣ 요청사항 입력 (선택)

양념 빼주세요, 포크 추가 등 요청사항이 있으면 입력

💡 메뉴에 없는 항목은 요청사항에 적어주세요!

5️⃣ 주문 완료

"주문 완료하기" 버튼 클릭

완료 메시지 확인 후 창 닫기 ✅

❓ 자주 묻는 질문

Q. 주문을 잘못했어요!

A. 같은 링크로 다시 들어가서 같은 이름을 입력하세요. "기존 주문 수정" 선택하면 수정할 수 있어요.

Q. 마감 시간이 지났어요

A. 마감 후에는 주문이 안 돼요. 총무에게 문의하세요.

Q. 링크가 안 열려요

A. 총무가 아직 주문을 생성하지 않았을 수 있어요. 총무에게 문의하세요.

💡 꿀팁

  • 메뉴는 가격이 비싼 순서대로 정렬되어 있어요
  • 주문 완료 후에도 마감 전까지는 수정 가능해요!
  • 창을 닫아도 주문은 저장돼요 ✅
