# 🍽️ 메뉴담기

단체 주문의 스트레스를 줄이는 간단한 주문 관리 시스템

## 🎯 프로젝트 소개

신문사 총무나 팀 리더가 배달 주문을 관리할 때 겪는 문제를 해결하기 위한 웹 애플리케이션입니다.

### 해결하는 문제점
- ❌ 카톡으로 주문 받으면 사람들이 확인을 잘 안 함
- ❌ 배민 장바구니가 하나밖에 없어서 여러 주문을 동시에 준비 불가
- ❌ 시간이 촉박해서 주문 정리가 어려움
- ❌ 저녁/디저트 따로 주문해야 해서 복잡함

### 제공하는 솔루션
- ✅ 웹 기반으로 누구나 쉽게 접속
- ✅ 여러 주문 세션 동시 관리 (저녁/디저트 분리)
- ✅ 실시간 주문 현황 확인
- ✅ 주문 내역 자동 정리 및 복사
- ✅ 마감 시간 자동 관리

## 🚀 사용 방법

### 1. 총무 (관리자)

1. **관리자 페이지 접속**
   - `admin.html`로 이동

2. **주문 세션 생성**
   - 주문 이름 입력 (예: "오늘 저녁", "금요일 디저트")
   - 식당 이름 입력
   - 마감 시간 설정
   - 메뉴 입력 (형식: `메뉴명|가격`)

3. **링크 공유**
   - 생성된 주문 링크를 카톡으로 팀원들에게 공유

4. **주문 현황 확인**
   - 대시보드에서 실시간 주문 현황 확인
   - 메뉴별 집계 자동 계산
   - 배민용 주문 텍스트 자동 생성

5. **배민 주문**
   - "주문 내역 복사" 버튼 클릭
   - 배민 "함께주문" 채팅에 붙여넣기

### 2. 팀원

1. **주문 링크 접속**
   - 카톡으로 받은 링크 클릭

2. **메뉴 선택**
   - 이름 입력
   - 원하는 메뉴와 수량 선택
   - 요청사항 입력 (선택)

3. **주문 완료**
   - "주문 완료하기" 버튼 클릭

## 📁 파일 구조

```
menudamgi/
├── index.html         # 메인 페이지 (시작점)
├── admin.html         # 관리자 페이지 (세션 생성)
├── order.html         # 주문 페이지 (팀원용)
├── dashboard.html     # 대시보드 (주문 현황)
├── app.js            # 핵심 로직 (로컬스토리지 관리)
├── style.css         # 스타일시트
└── README.md         # 이 파일
```

## 💻 기술 스택

- **프론트엔드**: HTML5, CSS3, JavaScript (Vanilla)
- **데이터 저장**: LocalStorage (별도 서버 불필요)
- **반응형 디자인**: 모바일 최적화

## 🔧 설치 및 실행

### 방법 1: 로컬에서 바로 실행

1. 파일 다운로드
2. `index.html`을 웹 브라우저로 열기

### 방법 2: 로컬 서버 실행 (권장)

```bash
# Python 3가 설치되어 있다면
python -m http.server 8000

# 또는 Node.js가 설치되어 있다면
npx http-server -p 8000

# 브라우저에서 접속
# http://localhost:8000
```

### 방법 3: GitHub Pages 배포

1. GitHub 저장소에 푸시
2. Settings → Pages에서 배포
3. 생성된 URL로 접속

## 🎨 화면 구성

1. **메인 페이지** - 관리자/팀원 선택
2. **관리자 페이지** - 세션 생성 및 관리
3. **주문 페이지** - 메뉴 선택 인터페이스
4. **대시보드** - 주문 현황 및 통계

## 🔍 개발자 도구

브라우저 콘솔에서 사용 가능:

```javascript
// 샘플 데이터 생성 (테스트용)
window.menudamgi.createSample()

// 모든 데이터 삭제
window.menudamgi.clearAll()

// 모든 세션 조회
window.menudamgi.getSessions()

// 특정 세션 조회
window.menudamgi.getSession('SESSION_ID')
```

## 📝 메뉴 입력 형식

관리자가 메뉴를 입력할 때 다음 형식 사용:

```
싸이버거|5900
통새우버거|6500
딥치즈버거|5500
케이준감자|2000
치즈스틱|2500
```

- 한 줄에 하나씩
- `메뉴명|가격` 형식
- 가격은 숫자만 입력 (원 단위)

## 💡 팁

1. **여러 주문 관리**: 저녁용/디저트용 세션을 따로 만드세요
