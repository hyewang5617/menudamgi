🍽️ 메뉴담기

단체 주문을 쉽게 관리하세요

관리자 (총무)

새로운 주문 세션을 만들거나 기존 세션을 관리하세요

팀원

총무가 공유한 주문 링크를 클릭하면 바로 주문할 수 있어요!

💡 주문 방법:

  1. 카톡으로 받은 주문 링크 클릭
  2. 이름 입력하고 메뉴 선택
  3. 주문 완료! 끝!

💡 사용 방법

  1. 총무: 관리자 페이지에서 식당과 메뉴를 입력하고 주문 세션을 생성
  2. 총무: 생성된 링크를 카톡으로 팀원들에게 공유
  3. 팀원: 링크를 클릭해서 원하는 메뉴 선택
  4. 총무: 마감 시간에 주문 내역을 확인하고 배민에 주문

단체 주문의 스트레스를 줄이는 메뉴담기 💚
